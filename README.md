# ☀️ 天气查询 · astrbot_plugin_weather

![天气查询](logo.png)

一个面向 **AstrBot v4**（≥ 3.5.19 的 Star 架构，已在 v4.27 验证）的天气查询插件，适用于个人 / 群聊场景。

## ✨ 功能

### 命令查询

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| `/天气 [城市]` | 实时天气 + 空气质量 + 今日趋势 + 未来三天 + 出行建议 + 气象预警 | `/天气 北京`、`/weather Tokyo` |
| `/预报 [城市]` | 未来 7 天预报（天气、气温、降水概率） | `/预报 上海`、`/forecast` |
| `/空气质量 [城市]` | AQI 数值、等级、首要污染物与浓度 | `/aqi 石家庄` |
| `/预警 [城市]` | 当前生效的气象预警（含完整预警正文） | `/预警 北京` |
| `/降雨 [城市]` | 未来 24 小时逐小时降水趋势 | `/降雨 广州` |
| `/对比 城市1 城市2…` | 2-5 个城市同屏对比（最热/最凉/空气最好），并发查询 | `/对比 北京 上海 广州` |
| `/设置` | 运行状态自检：数据源、绑定城市、订阅、缓存、时区 | `/设置`、`/status` |

### 个人化功能

- **`/绑定 [城市]`**：绑定个人默认城市（按发送者存储，重名城市会列出候选交互选择），之后 `/天气` 不带参数直接查询；`/解绑` 取消。
- **`/订阅 [城市] [时间] [工作日]`**：定时推送天气到当前会话，如 `/订阅 北京 07:30`。时间可省略（默认取配置项），也支持简写 `7`、`7点`、`7时30分`；加 `工作日` 则只在周一至周五推送，如 `/订阅 北京 7:30 工作日`。`/退订` 取消。绑定/订阅数据优先存 AstrBot 插件 KV 存储，旧版本自动回退本地 JSON；写入带互斥锁，多人同时绑定/订阅不会互相覆盖。
- **重名城市交互选择**：查询“朝阳”“海州”等重名城市时列出候选（所属省市），回复序号即可选择，45 秒超时自动取消。同一轮查询内只会询问一次，数据源回退时不会重复弹菜单。

### 展示与智能

- **图片卡片**：`/天气` 与 `/预报` 可渲染精美图片卡片（大字温度、AQI 彩色徽章、指标宫格、逐日预报条、出行建议、预警横幅）；渲染失败自动回退纯文本，可在配置中关闭。
- **出行建议**：按温度、降水概率、AQI、紫外线、风力自动推导“要不要带伞 / 防晒 / 戴口罩 / 防风”，不依赖具体数据源。
- **日出日落**：和风天气与 Open-Meteo 数据源会显示今日日出日落时间。
- **气象预警**：查询的城市有生效预警时（暴雨/雷电/高温等）自动附带预警标题与详情（按颜色分级标记 🔵🟠🔴⚠️）；也可用 `/预警` 单独查看**发布单位、失效时间、完整正文与防御指南**。已取消（`cancel`）与已过失效时间的预警会被自动过滤，不会误报。
- **拼音搜索**：城市名支持拼音，`/天气 beijing`、`/weather shanghai` 都能直接命中，不会误触发重名选择。
- **昨日对比**（Open-Meteo 数据源）：显示“最高温比昨天高/低 X℃”。
- **生活指数**（中国天气网数据源）：穿衣、紫外线、感冒指数一行提示。
- **AI 工具调用**：注册了 `get_weather` / `get_weather_forecast` / `get_air_quality` 三个 LLM 工具，AI 收到“北京天气怎么样”“未来几天适合出游吗”这类问题时会自动调用，无需手动输入命令；未指定城市时自动使用默认城市。
- **多数据源自动切换**（按优先级）：
  1. **和风天气（v1 新接口）**：配置 API Key 与专属 Host 后启用，数据最全；已全部迁移到和风 v1 新接口（`/weather/v1`、`/airquality/v1`、`/weatheralert/v1`，按经纬度查询，`X-QW-Api-Key` 请求头认证）。
  2. **中国天气网**：零 API Key、国内服务器直连 —— **国内部署开箱即用**；海外城市无实况时自动降级为仅预报模式。
  3. **Open-Meteo**：兜底（含独立空气质量与逐小时降水接口），适合海外服务器（国内服务器可能无法访问该域名）。
- **结果缓存**：同一城市 10 分钟内的重复查询直接返回缓存（上限 128 条，超出按最旧逐出）；缓存过期后仍会先用旧数据**秒回**并在后台刷新，不必每次重新等接口。
- **城市定位缓存**：城市搜索结果缓存 6 小时，避免每次查询都重复打一次搜索接口。
- **原生插件配置**：提供 `_conf_schema.json`，可在 AstrBot Web 面板的插件配置页直接编辑（无需改文件）。
- **零第三方依赖**：只用 Python 标准库，安装即用。

## 📦 安装

### 方式一：Web 界面上传 zip（推荐）

1. 打开 AstrBot Web 面板 → **插件管理** → **安装插件** → 上传 `astrbot_plugin_weather.zip`。
2. 安装完成后启用插件。

> ⚠️ 如果上传报 `FileNotFoundError: .../astrbot_plugin_weather`（zip 解压后找不到插件目录）：
> 这是 AstrBot v4 对“文件夹包裹型”zip 的解压兼容问题（服务器端把反斜杠路径当成普通文件名）。
> 本仓库提供的 `astrbot_plugin_weather.zip` 已改为**平铺结构**（文件直接在 zip 根目录，无外层文件夹），
> 走 v4 的“平铺”安装分支，**不会触发该错误**。请务必使用本 zip，不要自行重新压缩。

### 方式二：手动复制（最稳，绕过 zip 解压逻辑）

1. 把 `astrbot_plugin_weather` **整个文件夹**复制到 AstrBot 服务器的 `data/plugins/` 目录下：
   ```bash
   # 在服务器上（AstrBot 目录下）
   cp -r astrbot_plugin_weather /AstrBot/data/plugins/
   ```
2. 在 Web 面板重启 AstrBot（或重载插件）。
3. 插件管理中找到并启用。

### 服务器上自检 zip（可选）

```bash
unzip -l astrbot_plugin_weather.zip
# 期望看到 main.py / metadata.yaml / _conf_schema.json / config.json / README.md
# 直接列在根目录（正斜杠、无外层文件夹、无反斜杠）
```

## 🚀 使用方法

> 命令前缀 `/` 是 AstrBot 默认值（`wake_prefix`），可在设置中修改，改后命令自动跟随新前缀。
> v4 中命令名与参数之间**必须有空格**：`/天气 北京` ✅，`/天气北京` ❌。
> 城市带空格也没问题：`/weather New York` ✅。

```
/天气 北京          # 实时天气（默认渲染图片卡片）
/预报               # 使用绑定/默认城市的 7 天预报
/空气质量 石家庄    # AQI 与污染物详情
/预警 北京          # 当前生效的气象预警（完整正文）
/降雨 广州          # 未来 24 小时降水趋势
/对比 北京 上海     # 多城对比（并发查询，几乎同时返回）
/绑定 北京          # 绑定个人默认城市
/天气 beijing       # 拼音也能查
/订阅 北京 07:30    # 每日 07:30 推送北京天气
/订阅 北京 7:30 工作日   # 只在工作日推送
/退订               # 取消订阅
/设置               # 查看插件运行状态（排障用）
```

也可以直接问 AI："北京今天天气怎么样？"“未来三天杭州会下雨吗？”（需在 AstrBot 中开启工具调用，且模型支持）。

## ⚙️ 配置

Web 面板 → 插件管理 → 该插件的 **配置** 页（基于 `_conf_schema.json` 自动生成）：

| 配置项 | 说明 |
| --- | --- |
| `qweather_api_key` | 可选（推荐）。和风天气 API Key（免费申请：[和风天气控制台](https://console.qweather.com/)）。填写后优先使用和风天气；留空则用中国天气网（零 Key）。 |
| `qweather_api_host` | 可选。和风天气**专属 API Host**（控制台 → 设置 中查看，形如 `abc123.qweatherapi.com`，只填域名即可）。**2024 年后新注册的和风用户必填**；和风 WebAPI v7 已全线弃用，本插件使用仅支持专属 Host 的 v1 新接口，只填 Key 不填 Host 时会跳过和风数据源并在日志告警。 |
| `default_city` | 可选。默认城市，如 `北京`。命令不带城市且未绑定时使用（AI 工具未指定城市时也会使用）。 |
| `image_card` | 默认 `true`。渲染图片天气卡片；关闭后始终返回纯文本。渲染失败时自动回退纯文本。 |
| `interactive_choice` | 默认 `true`。重名城市时列出候选交互选择；关闭后直接取第一个候选。 |
| `push_time_default` | 默认 `07:30`。`/订阅` 未指定时间时使用的每日推送时间（HH:MM）。 |
| `timezone` | 默认留空（用服务器本地时区）。订阅推送与“当前时间”的时区，如 `Asia/Shanghai`。**服务器跑在 UTC（常见于 Docker）时务必填**，否则 `/订阅 07:30` 会在北京时间 15:30 推送。 |

> 兜底：插件目录下的 `config.json` 也可配置（格式同上），面板中留空的项会用它逐项补齐。
> 不确定配置是否生效时，发一条 `/设置` 即可看到实际使用的数据源、时区、绑定与订阅状态。

## ❓ 常见问题

- **装好插件发 `/天气` 没反应/很慢**：国内服务器访问 Open-Meteo（国外域名）通常超时。本插件已默认使用**中国天气网**（国内直连）；若仍慢，检查服务器到 `d1.weather.com.cn` 的连通性。
- **配置了和风 Key 但一直回退到中国天气网**：2024 年后新注册的和风账号只有专属 API Host 可用（且 v1 新接口仅支持专属 Host），请在插件配置中同时填写 `qweather_api_key` 和 `qweather_api_host`（[查看方法](https://dev.qweather.com/docs/configuration/api-host/)）。
- **收不到订阅推送 / 推送时间不对**：部分平台（如 QQ 官方接口）限制机器人主动发消息，属平台侧限制；确认平台适配器支持 `context.send_message` 主动消息。插件每 25 秒检查一次到点订阅，同一订阅每天只发一次。若**时间不对**，多半是服务器时区为 UTC（Docker 默认），在配置里填 `timezone: Asia/Shanghai`，或用 `/设置` 核对“当前时间”。
- **配置到底生效没有**：发 `/设置` 查看实际使用的数据源、时区、绑定城市与订阅列表，一眼就能定位问题。
- **和风 API KEY 的长期可用性**：和风官方公告，**2027-01-01 起将限制 API KEY 方式的每日请求量**，并推荐改用 JWT（Ed25519）认证。本插件目前使用 API KEY（`X-QW-Api-Key` 请求头，零第三方依赖）；如果你调用量较大，可考虑改用中国天气网（零 Key）或后续接入 JWT。
- **卡片没渲染出来**：卡片依赖 AstrBot 的 HTML 渲染器（Web 面板可配置），渲染失败会自动回退纯文本，功能不受影响。
- **AI 不自动调用工具**：确认 AstrBot 中已启用“工具调用 / Function Calling”，且当前模型支持。
- **查询不到城市**：使用标准城市名（如“北京”“上海”），偏远地区可试试附近大城市；海外城市在中国天气网无实况数据，会自动转为仅预报模式，或配置和风天气 / 使用 Open-Meteo 可达的服务器。
- **预警/指数有时候没有**：仅当该城市当前确有生效预警时才显示；生活指数仅中国天气网数据源提供。
- **小时降雨查不到**：中国天气网不提供逐小时降水，该命令走和风天气或 Open-Meteo；两者都不可达时会提示“暂无小时降雨数据”。
